## Контекст (зачем фаза)

После фазы 0 есть пакеты, vitest и токены. Фаза добавляет чистые функции: форматирование PLN и деление счёта в грошах.
Потребитель — фаза 3 (суммы, прогресс) и фаза 4 (правка цены). Это «вся сложность под капотом» из критериев жюри.

## Что делаем

`money.ts` и `split.ts` — чистые функции без React и стора, плюс тесты. Источник истины — `docs/SPEC.md`, разделы «Данные → Состояние сессии» и «Логика деления».
Все деньги — целые гроши. Никаких float в результатах.

## Критерий «работает» (формулируем ДО кода)

1. `npm test; echo exit=$?` → `exit=0`, видны тесты: одна позиция на троих (1000 гр → 334/333/333), пустые клеймы, всё взято, сервис 0, сервис ≠ 0, хост ничего не тапал, инвариант.
2. Инвариант: для фикстуры и ≥ 500 случайных комбинаций клеймов (детерминированный PRNG с фиксированным seed, без нового пакета) `Σ shareOf === total` и все доли — целые ≥ 0.
3. `formatPLN(21450)` → `214,50 zł` (тест нормализует NBSP: `.replace(/ /g, ' ')`); `formatPLN(21449.6)` → `214,50 zł` (округляет вход — для анимированных сумм фазы 3).
4. `npx tsc --noEmit; echo exit=$?` → `exit=0`.

- Никаких новых пакетов без строки в `docs/DECISIONS.md` и проверки, что версия реально встала (`npm i` → что записалось в манифест).

## Решения, которые фаза фиксирует (записать в DECISIONS.md, SPEC не уточняет)

- `total = Σ items.priceGrosze + serviceGrosze`.
- Порядок «по порядку входа» = порядок в `session.participants`.
- Позиция на n человек: `floor(price/n)` каждому, остаток по 1 гр первым по порядку входа.
- Сервис: пропорционально доле позиций (включая невзятое у хоста); `floor`, остаток — по наибольшему дробному остатку, при равенстве — по порядку входа. Если `Σ items = 0` — весь сервис хосту.
- `allocated` = доли взятых позиций + их часть сервиса; при «всё взято» `allocated === total`.
- `formatPLN` сам делает `Math.round` входа: `useSpring` в фазе 3 даёт дробные гроши, а компонентам округлять запрещено.
- `parsePLN` принимает `214,50` / `214.50` / `214` (с `zł` и пробелами или без), иначе `null`.

## Шаги (один за раз: диф → команда проверки → реальный вывод → STATE.md → коммит)
