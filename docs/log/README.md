# docs/log — архив

Сюда переезжает всё, что вытесняется из `docs/STATE.md`: секция «Сделано» прошлых фаз, финальные отчёты по фазам, разборы инцидентов.
Один файл на месяц: `YYYY-MM.md`, только дописывается. При старте сессии не читается — агент открывает его по ссылке из STATE, когда нужна археология.
